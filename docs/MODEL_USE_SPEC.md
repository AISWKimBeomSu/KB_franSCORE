# FranSCORE 모형 사용 명세

> 이 문서가 이 저장소의 **1순위 산출물**이다. 성능표보다 먼저 읽어야 한다.

미 연준 SR 26-2(2026.4.17 시행, SR 11-7·SR 21-8 대체)는 모형 리스크의 가장 큰 원천으로
성능 부족이 아니라 **오용**을 지목한다.

> "설계 목적에 부합하는 정확한 산출물을 내는 근본적으로 건전한 모형조차
> 오용·오적용되면 높은 모형리스크를 보일 수 있다."

참고 분석 도구가 은행에서 거부되는 실제 사유는 판별력이 낮아서가 아니라 **"어디까지 쓸 수
있는지 모르겠다"** 이다. 그래서 범위를 먼저 못박는다.

---

## 1. 모형 식별

| 항목 | 값 |
|---|---|
| 명칭 | FranSCORE 브랜드 리스크 평가 |
| 산출물 | 브랜드 등급 `FS1/FS2/FS3` · 악화 전환 확률 · 브랜드 상태 · 진단 소견 |
| 평가 단위 | **프랜차이즈 브랜드** (차주·점포가 아니다) |
| 대상 모집단 | 외식업 · 누적 가맹점 30개 이상 · 3년 연속 공시 (2024년 자격 1,442개 브랜드) |
| 자료 원천 | 공정거래위원회 가맹사업 공시, 금융감독원 전자공시(DART), 네이버 검색어트렌드·뉴스 |
| 모형 유형 | LightGBM 이진분류 + isotonic 보정 + 규칙기반 진단 34종 |
| 관측기간 | 2016~2024 (9년) |
| 갱신 주기 | 등급·확률 **연 1회**(공시 갱신 시) · 진단 소견·점검 순위 **일 1회** |

**SR 26-2 중요도 분류**: 규제자본·규제보고·자동 여신결정에 사용하지 않으므로 **low-purpose**.
비중요 모형의 최소 요건 3가지를 이 문서가 충족한다 — (a) 인벤토리 등재, (b) 성과 모니터링,
(c) 중요도 전환 조건 정의(§5).

## 2. 허용 용도

1. **2선 리스크 관리의 점검 우선순위 산정.** 어느 브랜드를 먼저 들여다볼지 정하는 큐.
2. **브랜드 단위 집중도 모니터링.** 특정 브랜드에 여신이 쏠렸는지, 그 브랜드의 상태가
   어떤지를 함께 보는 용도.
3. **심사 시 참고 정보.** 심사역이 차주 심사에 더해 "이 브랜드는 지금 어떤 상태인가"를
   확인하는 보조 자료. **판단의 근거이지 판단 자체가 아니다.**
4. **포트폴리오 상관·집중 위험 논의의 출발점.** 브랜드가 공통 위험요인이라는 실증
   (ρ_W = 0.416 vs ρ_B = 0.005) 위에서 브랜드 단위 관리의 필요성을 검토하는 용도.

## 3. 금지 용도

아래는 **하지 말아야 한다.** 각 항목에 왜인지를 적는다.

| 금지 | 이유 |
|---|---|
| **자동 여신 승인·거절** | 등급은 차주의 상환능력이 아니라 브랜드 상태다. 우량 브랜드의 부실 점포와 부실 브랜드의 우량 점포가 모두 존재한다. |
| **여신 한도 산정** | 등급별 확률은 부도확률이 아니다(§4). 한도 공식에 대입하면 근거 없는 숫자가 나온다. |
| **금리 산정·차등** | 위와 동일. 가격에 반영하려면 부도·손실 실적으로 검증된 PD·LGD가 필요하고, 우리에게는 없다. |
| **규제자본(IRB) 산출** | 바젤 IRB 등급체계 요건(세칙 149.나 차주등급 7개+부도 1개, 180.라 등급별 PD 추정)을 충족하지 않는다. 애초에 그 용도로 설계되지 않았다. |
| **IFRS 9 충당금 산정 · Stage 이동 판정** | 등급 이동이 절대 신용위험 변화를 뜻하지 않는다. |
| **개별 가맹점주에 대한 불이익 처분의 단독 근거** | 브랜드 등급으로 차주를 판단하는 것은 연좌다. |
| **"부도확률"·"PD"로 표기하거나 그렇게 인용** | §4 참조. 이름을 바꾸는 순간 거짓이 된다. |
| **대외 공표·마케팅 자료에 브랜드 등급을 개별 명시** | 실명 브랜드에 대한 신용훼손 위험. 내부 참고용이다. |

## 4. 산출물의 정확한 의미 — 반드시 읽을 것

### 등급은 부도확률이 아니다

`FS3 주의`의 밴드는 **"향후 1년 내 업종 하위구간 악화 전환 확률 16.0% 이상"** 이다.
여기서 '악화'는 우리가 만든 말이 아니라 **공정거래위원회 가맹사업 공시 지표의 관측 사건**이다.

- 가맹점수 · 계약종료율 · 평균매출액 · 면적당매출액이
- **업종 × 연도 하위 구간(하위 20%)** 에 진입하는 사건이
- 2개 이상 동시 발동하거나 1개가 극단(하위 5%)일 때

즉 **상대 분위수 정의**다. 그래서 두 가지가 따라온다.

1. **산업 전체가 나빠져도 사건 발동률은 거의 일정하다.** 실측 연도간 표준편차 0.64%p
   (계약종료 사건은 0.09%p). 정의상 그렇다. 이 지표로 **경기 국면을 읽을 수 없다.**
2. **밴드 문구를 "부실 확률"로 읽으면 과대 해석이다.** 밴드는 반드시 다음 형식으로만
   표기한다 — `FS3 주의 · 업종 하위구간 악화 전환 확률 16.0% 이상 (검증 실현율 30.2%, n=182)`.

### 등급 옆의 '상태'가 더 중요할 수 있다

| 상태 | 정의 | 2024 코호트 | 성능 근거 |
|---|---|---|---|
| **건전** | 산출연도 악화사건 0건, 판정 지표 관측 | 892 (61.9%) | ✅ 있음 — 학습·보정·평가 모집단 |
| **요주의** | 산출연도 악화사건 이미 발동 | 496 (34.4%) | ⚠️ 모형 근거 없음 → 실현율표 |
| **평가불가** | 판정 지표 미관측 | 54 (3.7%) | — 등급 부여 안 함 |

**요주의 구간에는 모형 판별력 근거가 없다.** 라벨이 healthy-gate 로 만들어져
`labels.parquet` 에 그 행이 아예 없고, 따라서 이 구간에서는 AUC·Lift 를 잴 수 없다.
보고된 판별력(AUC 0.707 [0.671, 0.742], Lift@10 2.52)은 **전부 건전 구간에서만** 측정된 값이다.

**그러나 '아무것도 못 잰다'는 뜻은 아니다.** 라벨 표본이 없을 뿐 상태 전이는 패널에서
그대로 셀 수 있고, 실제로 셌다 (`outputs/watch_base_rates.csv`, 2018~2023 쌍 5,694건,
점수 산출과 동일한 자격 게이트):

| 산출연도 상태 | 사건수 | 표본 | 다음 해 재발동 | Wilson 95% |
|---|---|---|---|---|
| 건전 | 0 | 3,657 | 9.4% | [8.5, 10.3] |
| 요주의 | 1 | 1,218 | **24.1%** | [21.7, 26.5] |
| 요주의 | 2 | 536 | **45.9%** | [41.7, 50.1] |
| 요주의 | 3 | 125 | **64.8%** | [56.1, 72.6] |

요주의 전용 모형도 만들어 봤지만 기각했다 — 워크포워드 macro AUC 0.6937 로
**계약종료율 단일변수(0.7066)보다 못하다**. 그래서 순위를 매기지 않고 실현율만 공표한다.
같은 사건수 안에서는 전부 같은 확률이며, 그것이 이 구간에 대해 아는 전부다.

화면과 CSV 는 이 상태를 항상 함께 표시한다. **요주의 브랜드는 등급의 확률값이 아니라
사건수 실현율과 진단 소견(관측 사실)으로 판단하라.**

### 등급별 실현 악화율 (앵커)

보정 자료는 **운영 모형 점수, 학습 연도(2018~2021) 제외** — 2022~2023, 1,429행 · 악화 141건.
학습 연도 점수는 in-sample 이라 쓰지 않는다(포함 시 Spiegelhalter Z=+28.9 로 파탄).

| 등급 | 밴드 | n | 악화 | 실현율 | 95% 신뢰구간 |
|---|---|---|---|---|---|
| **FS1 안정** | 4.5% 미만 | 631 | 14 | **2.22%** | [1.2, 3.7] |
| **FS2 관찰** | 4.5 ~ 16.0% | 616 | 72 | **11.69%** | [9.3, 14.5] |
| **FS3 주의** | 16.0% 이상 | 182 | 55 | **30.22%** | [23.6, 37.5] |

인접 등급의 신뢰구간이 겹치지 않고(최소 분리 5.56%p), 두 해 모두 단조 증가한다.
시점 밖 확인(2022 적합 → 2023 적용, 같은 컷)에서도 2.32% → 8.67% → 19.64% 로 단조다.

**등급이 3개인 이유**: 4등급 이상은 보정연도를 제외한 진짜 OOS 에서 인접 신뢰구간이
겹치고, 연도를 하나씩 빼고 재도출하면 최상위 등급이 붕괴한다(실측). 신용평가사도
18~20 notch 로 부여하되 부도율 통계는 6개 버킷으로만 공표한다 —
**표본이 지지하지 않는 세분화는 검증표에서 접는 것이 업계 표준이다.**

## 5. 중요도 전환 조건 (SR 26-2 요구)

아래 중 **하나라도** 해당하면 이 모형은 더 이상 비중요 모형이 아니며,
정식 모형 검증 절차를 거쳐야 한다.

1. 등급·확률이 **여신 승인·거절·한도·금리 결정에 직접 입력**되기 시작할 때
2. 규제자본·충당금 산출 경로에 연결될 때
3. 이 도구를 참조해 관리되는 여신 잔액이 **자영업자 포트폴리오의 유의한 비중**에 이를 때
4. 대외 공표물(IR·공시·마케팅)에 산출물이 인용될 때

## 6. 알려진 한계 (전부 실측)

1. **라벨이 상대 분위수다.** 절대적 위험 수준을 측정하지 않는다(§4).
2. **요주의 구간에 모형 판별력 근거가 없다.** 코호트 1,442개 중 496개(34.4%)가 요주의이고,
   주의(FS3) 등급 366개 중 271개(74.0%)가 여기 속한다. 학습 모집단 밖(요주의+평가불가)은
   550개(38.1%)다. 이 구간은 모형 대신 **실현율표**로 답한다 — 다음 해 재발동률이
   사건 1건 24.1% / 2건 45.9% / 3건 64.8% (건전 9.4% 대비 2.6~6.9배,
   `outputs/watch_base_rates.csv`). 순위는 매기지 않는다.
3. **커버리지는 세 기준으로 함께 읽어야 한다.**

   | 기준 | 값 |
   |---|---|
   | 브랜드 수 (외식 패널 9,333개 대비) | **15.5%** (1,442개) |
   | **점포 가중 (외식 내)** | **73.6%** (135,035 / 183,399개) |
   | 점포 가중 (전 업종) | 35.6% (135,035 / 379,430개) |

   브랜드 수로는 15.5% 지만 **외식 가맹점 4곳 중 3곳**이 평가 대상 안에 있다. 못 보는
   브랜드가 대부분 아주 작기 때문이다 — 2024년 공시 전 업종 11,718개 중 가맹점 10개
   미만이 8,164개(70.0%)이고, 이들은 분모가 작아 성장률·계약종료율이 잡음에 지배된다.
   공정거래위원회가 공표한 전국 가맹점 수는 379,739개인데 우리 패널의 전 업종 합계가
   379,430개로 **99.92% 일치**한다(수집 누락이 사실상 없다는 뜻이다).
   공정위 등록 브랜드 총수 13,725개는 2025년 공표치이며 우리 2024 패널(11,718개)과
   기준연도가 다르다 — 같은 표에 나란히 놓지 않는다.
4. **본부 재무를 대부분 못 본다.** 브랜드 기준 11.4%, 점포 가중 37.1%.
   외부감사 대상이 아닌 본부는 감사보고서를 내지 않는다.
   게다가 **재무 보유 자체가 안전성 대리변수**다(보유 브랜드 양성률 3.2% vs 미보유 10.0%).
5. **위약금·본부 대여금을 못 본다.** 폐업 시 우발채무가 되는 영업위약금, 그리고
   본부→가맹점 대여금은 우리가 수집한 공시 항목 어디에도 없다.
   **회수율에 직접 영향을 주는 두 항목이 공시에 없다** — 추정하지 않고 없다고 밝힌다.
6. **OOS 관측이 3년(2021~2023)뿐이다.** 경기 국면 하나도 온전히 담지 못한다.
7. **표본이 작다.** 검증 악화 141건. 신뢰구간이 넓다는 사실을 지표와 함께 공표한다.
8. **실제 여신 부도·연체 라벨이 없다.** 어떤 산출물도 PD 가 아니다.
9. **외식업에 한정.** 도소매·서비스는 패널에 있으나 현행 트랙에서 제외돼 있다.
10. **모형의 우위가 입증되지 않았다.** 워크포워드 fold 델타 t-구간에서 LightGBM 이
    유의하게 넘어서는 것은 자기상관 기준선 하나뿐이며, 계약종료율 단일변수·로지스틱과는
    통계적으로 동등하다. LightGBM 을 쓰는 근거는 성능이 아니라 SHAP 요인 분해다.

## 7. 재현

```bash
python run_pipeline.py --step all       # 수집 → 패널 → 피처 → 라벨 → 학습 → 평가 → 점수
python tools/derive_grade_bands.py      # 등급 밴드 도출 + 검증표 + 배포용 보정기
python tools/check_doc_numbers.py       # 문서 수치 ↔ 산출물 대조
```
