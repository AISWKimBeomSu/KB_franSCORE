# 화면 디자인 기준

이 문서는 **취향이 아니라 검증 가능한 기준**만 적는다. 여기 적힌 수치는
`tests/test_theme_contrast.py` 가 매번 다시 계산해 지킨다. 눈으로 고친 것은
눈으로 다시 무너지기 때문이다.

정의는 `src/theme.py` 한 곳에 있다. 화면 코드(`src/views/*.py`)는 값을 직접
적지 않고 토큰을 참조한다.

## 1. 색 — 글자용과 도형용을 나눈다

접근성 기준이 서로 다르다.

| 대상 | 기준 | 근거 |
|---|---|---|
| 본문 글자 | 4.5 : 1 | WCAG 2.1 · 1.4.3 |
| 굵은 18.66px+ / 24px+ 글자 | 3 : 1 | WCAG 2.1 · 1.4.3 |
| 도형 · 그래프 · 경계 | 3 : 1 | WCAG 2.1 · 1.4.11 |

하나의 색으로 둘 다 감당하면 반드시 한쪽이 깨진다. 그래서 토큰을 둘로 나눴다.

| 의미 | 글자 | 페이지 배경 대비 | 도형 | 대비 |
|---|---|---|---|---|
| 주의 | `DANGER` #B44C46 | 4.70 | `DANGER_FILL` #C8433B | 4.42 |
| 관찰 | `WARN` #986216 | 4.66 | `WARN_FILL` #C07C1B | 3.11 |
| 안정 | `SAFE` #287B57 | 4.70 | `SAFE_FILL` #1F8A5B | 3.94 |
| 정보 | `INFO` #3D6EA4 | 4.82 | `INFO_FILL` #2F6FB5 | 4.70 |

글자 계열.

| 토큰 | 값 | 배경 대비 | 쓰임 |
|---|---|---|---|
| `INK` | #26221E | 14.6 | 제목 |

| `TEXT_MUTED` | #766E65 | 4.56 | 캡션 · 출처 |

사이드바(배경 `NAV_BG` #332F2A).

| 토큰 | 값 | 대비 |
|---|---|---|

### 고친 것

이 기준을 세우기 전 실측값이다. 배경 #F5F4F1 위 기준.

| 대상 | 이전 | 이후 |
|---|---|---|
| 사이드바 비활성 메뉴 | **1.14** | 8.01 |
| 관찰 #D9860F | 2.59 | 4.66 |
| 보조 텍스트 #9A9289 | 2.79 | 4.56 |
| 사이드바 고지문 | 2.78 | 4.97 |
| 안정 #1F8A5B | 3.94 | 4.70 |
| 주의 #C8433B | 4.42 | 4.70 |
| 입력 안내문(Streamlit 기본) | 3.70 | 5.37 |

사이드바 1.14 의 원인은 특이도 역전이었다. `[data-testid="stSidebar"] *` 는
(0,1,0) 인데 본문 규칙 `[data-testid="stMarkdownContainer"] p` 가 (0,1,1) 이라
**본문 규칙이 이긴다**. Streamlit 은 버튼 라벨을 `stMarkdownContainer > p` 로
렌더하므로 메뉴 글자가 본문색이 되어 딥톤 배경 위에 얹혔다.

색을 고를 때는 **색조와 채도를 원래 값 근처에 묶고 명도만 최소한 낮췄다.**
채도를 최대로 올리면 대비는 쉽게 오르지만 #DB0C00 같은 원색이 되어
"은행 화면이므로 경고를 과장하지 않는다"는 전제를 깬다.

## 2. 타이포 — 여덟 단계

| 토큰 | 크기 | 쓰임 |
|---|---|---|
| `FS_XS` | 13px | 배지 · 범례 · 표 안 보조 |
| `FS_SM` | 14px | 캡션 · 출처 · 근거표기 |
| `FS_MD` | 15px | 조밀한 목록 · 버튼 · 입력 |
| `FS_BASE` | 16px | 본문 |
| `FS_LG` | 18px | 카드 제목 · 강조 본문 |
| `FS_XL` | 22px | 섹션 제목 (h3) |
| `FS_2XL` | 28px | 페이지 부제 (h2) |
| `FS_3XL` | 34px | 페이지 제목 (h1) · 지표 숫자 |

**13px 이 바닥이다.** 이전 화면에는 10px(게이지 눈금) · 11px(등급 라벨) ·
11.2px(사용범위 고지)가 있었다. 매일 몇 시간씩 보는 심사역에게 11px 은
읽으라고 준 크기가 아니다. 특히 고지문은 법적 성격이라 작게 흘려둘 대상이 아니다.

이전에는 소스에 `.76 .78 .8 .82 .84 .85 .86 .87 .88 .9 .92 .95 .96 .97 .98
.99 1 1.02 1.04 1.05 1.06 1.08 1.14 1.18 1.26 1.4 1.75 1.9 2rem` — **29종**이
있었고 브라우저 렌더 기준 28종이었다. 0.02rem 차이는 아무도 의도한 적 없고
아무도 구분하지 못한다.

차트 글자는 CSS 밖이라 plotly 템플릿에 px 로 같은 계단을 다시 적는다
(눈금 13 · 범례/본문 14 · 제목 16).

> ⚠️ `st.plotly_chart` 는 기본값이 `theme="streamlit"` 이고, 그 경우 Streamlit 이
> **자기 템플릿으로 KB 템플릿을 덮어쓴다.** trace 에 직접 준 marker 색만
> 살아남아서 색이 맞으니 테마가 먹은 줄 알기 쉽다. `theme.plot()` 이
> `theme=None` 을 넘겨 이를 막는다.

## 4. Streamlit 기본값 중 반드시 덮어야 하는 것

손대지 않으면 KB 팔레트 한가운데 프레임워크 기본색이 그대로 나온다.

| 요소 | 기본값 | 처리 |
|---|---|---|
| 멀티셀렉트 태그 | #FF4B4B (형광 빨강) | 옐로 틴트 + 잉크 글자 |
| 지표 증감 배지 | 회청색 pill | 웜 그레이 + 보더 |
| 입력 안내문 | rgba(49,51,63,.6) | `TEXT_SUB` |
| 인라인 `code` | 10.5px | `FS_SM` |
| 지표 이름 | 한 줄 + 말줄임 | 줄바꿈 허용 |

지표 이름을 말줄임하면 안 되는 이유: 1024px 에서 `주의 · 100점포 이상` 이
`주의 · 100점포 이…` 로 잘렸다. 지표 이름이 잘리면 그 숫자가 무엇의 숫자인지
알 수 없다 — 지울 수 있는 정보가 아니다.

## 5. 계측 방법

브라우저에서 잴 때 **트랜지션과 애니메이션을 먼저 정지시킨다.**

```
*,*::before,*::after { transition:none!important; animation:none!important }
```

정지시키지 않으면 `getComputedStyle` 이 트랜지션 **시작값**을 돌려준다.
실제로 이 때문에 사이드바 배경이 밝은 회색으로 측정돼 명도대비 1.14 결함이
한동안 가려져 있었다. 인라인 `!important` 를 넣어도 값이 안 바뀌는 것이 신호다.

명도 계산은 반드시 표준값으로 자기 검증한다.

| 조합 | 정답 |
|---|---|
| 검정 / 흰 | 21.00 |
| #767676 / 흰 | 4.54 |

배경은 조상을 거슬러 올라가며 **알파를 합성**해야 한다. `rgba(49,51,63,0.1)` 을
원색으로 계산하면 밝은 회색 배경을 어두운 색으로 오판해 없는 결함을 만든다.

## 6. 화면별 실측 (1512px · 1280px · 1024px)

전 화면에서 다음이 0건이다.

- 명도대비 미달
- 13px 미만 글자
- 가로 넘침 · 글자 잘림
- 저해상도 이미지 (표시 크기보다 원본이 작은 경우)

대상: FRANSCORE 목록 · 브랜드 상세(5개 탭 전부) · 점검 큐 ·
여신 포트폴리오 · AI 상담 · 서비스 소개.

렌더된 글자 크기는 13 · 14 · 15 · 16 · 18 · 22 · 34px 로 수렴했다
(21px 은 로고 대체 글자 마크로, 타일 크기에 비례하는 값이라 예외).
